# FoodCar

FoodCar is a Flutter-based food discovery and ordering application.

## Project Structure

- `lib/` Core application source code
- `assets/` Static JSON data and branding assets
- `android/`, `ios/`, `web/`, `linux/`, `macos/`, `windows/` Platform runners

## Future Implementations

- Add authentication + profile persistence with Firebase Auth.
- Add a real backend data source (Firestore or REST API) for restaurants and menu data.
- Integrate payment flow (UPI/cards/wallet) and order tracking.
- Add push notifications for order status updates.
- Add analytics events for funnel tracking and conversion improvements.
- Improve test coverage (unit, widget, and integration tests).
