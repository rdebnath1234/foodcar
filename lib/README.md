# Lib Module Guide

This folder contains app logic, UI screens, widgets, and state management.

## Future Implementations

- Move to feature-first folder structure (`features/cart`, `features/auth`, etc.).
- Add a repository layer to decouple UI from data providers.
- Introduce dependency injection (for example, `get_it` or `riverpod` providers).
- Add centralized app theming with light/dark support.
- Add robust error handling and user-friendly failure states.
- Add localization support for multiple languages.
