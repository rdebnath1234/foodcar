# Screens Module Guide

This folder contains user-facing pages and screen-level presentation logic.

## Future Implementations

- Standardize navigation flow using named routes or `go_router`.
- Add loading, empty, and error states for all data-driven screens.
- Build reusable screen templates for list/detail/cart flows.
- Improve accessibility (semantic labels, contrast, scalable text).
- Add responsive adaptations for tablet and desktop layouts.
- Add widget tests for key user journeys (browse -> cart -> checkout).
